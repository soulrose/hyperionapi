        นำเข้าจาก Postman

        จาก Postman ในเครื่องนี้ (รวม request แบบ GraphQL)

        อ่านจากโปรแกรม Postman ที่ติดตั้งอยู่โดยตรง — ไม่ต้อง export, ไม่แก้อะไรใน Postman

        จากไฟล์ที่ export

        Collection (v2.1) หรือ Environment ที่ export เป็น .json — request แปลงเป็น *.req.yaml, ค่า secret ของ env ย้ายไป secrets.local.yaml

        หรือวาง cURL / GraphQL query

        request แบบ GraphQL ของ Postman export ไม่ได้ — เปิด request นั้นใน Postman แล้วคัดลอก Code (</>) → cURL หรือคัดลอก query จากแท็บ Query มาวางที่นี่
